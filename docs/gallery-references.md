# Riferimenti per la galleria tridimensionale

Ricerca GitHub del 21 settembre 2026. L’idea scelta è una sala percorribile con camera in prima persona e fotografie reali alle pareti.

| Repository | Interesse per il progetto | Impiego |
| --- | --- | --- |
| https://github.com/theringsofsaturn/3D-art-gallery-threejs | Galleria d’arte interattiva in Three.js, tutorial di Emilian Kasemi | Riferimento concettuale; nessun codice o asset copiato. Licenza non dichiarata nei metadati consultati. |
| https://github.com/mattvr/vr-art-gallery | Presentazione di opere ad alta risoluzione in WebXR | Riferimento per lo spazio espositivo; licenza MIT. Non è stato integrato WebXR. |
| https://github.com/bizarro/infinite-circular-webgl-gallery | Galleria circolare WebGL con shader | Alternativa per una navigazione fotografica astratta; licenza MIT. Non utilizzata nella sala. |
| https://github.com/mrdoob/three.js | Motore 3D in JavaScript | Unica dipendenza integrata, versione npm 0.186.0, MIT. Licenza inclusa nella build. |

Sala, geometrie architettoniche, illuminazione, controlli, mappa e navigazione sono implementati nel repository UnconventionArt. Nessun modello o fotografia dimostrativa di terzi è stato incorporato.
